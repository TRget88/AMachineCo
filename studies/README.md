# Studies

The three.js study mockups in this folder are copied from the vehicle repositories on Nurbly by `node tools/sync.mjs`. Do not edit them here. Change them in their own repository and run the sync again.

Each mockup keeps its own licence, the CERN Open Hardware Licence version 2, weakly reciprocal (`CERN-OHL-W-2.0`). The source of each one is listed in `studies.json`.
